# Ganjuko Balance Audit — Lv50 Simulator Results

Generated by `work/sim/simulate.mjs` (seed 20261101, reproducible). Raw data: `work/sim/results.json`.

## Model

- Stats from Classes.json params[*][50]; BST = MHP+ATK+DEF+MAT+MDF+AGI at Lv50 (MMP/LUK excluded).
- Type multiplier: NEW chart v1 vs defender type1 only (all species single-type). STAB 1.5, crit 1.5 @ p=1/16, roll 0.85-1.00, min 1 dmg if effectiveness > 0.
- Heals at face value, max 3 uses/move/battle. Status/buff utility fixed at 30 HP-equivalent, once/battle, no state tracked.
- MP costs not modelled. Damaging moves with status riders scored as pure damage.
- Move selection: best expected value (damage = formula x type mult x STAB x accuracy; heal = min(missing HP, heal) x 0.9, max 3 uses/move; status/buff = fixed utility 30, once per battle).
- Higher AGI first, 100-round cap, HP fraction breaks the cap. All 72 skills in current data have successRate 100, so accuracy never misses in practice.

### What drives the extremes

- **Evolution stage dominates.** Final forms average 71.7% win rate vs 32.7% for unevolved species; mean BST 3075 vs 2270 (overall BST range 1634-3730). The bottom 20 is almost entirely unevolved "kit/ling" forms — expected against a field of final forms, and the reason competitive modes must field final forms or scale stats, not just levels.
- **The top is a speed-and-cannon template, not 20 individual designs.** Every top-20 species is a final form with BST 3046-3730 in the top AGI band (373-405), running a templated 4-move set ending in a 4.0x+ "cannon" move (Supernova, Hydro Cannon, Earthquake/Tectonic Slam class). Battles are usually decided in 1-3 hits, so moving first with a cannon is the whole game.
- **Broken outlier: #57 Stormcresteon (Astral) won 100.0% of 83 battles.** #165 Terratailius (99.0%), #273 Thunderdiveoid (98.9%), #93 Torrentblastagon (98.8%) and #105 Cyclonebloommon (98.8%) are the same template at the same speed tier — a class of outliers, not one bad row.
- **Worst "real" outlier class: Normal kits.** #385 Typhoonroarling (2.1%), #112 Infernoroarkit (2.5%), #274 Granitesurgekit (3.4%), #85 Cryostrikekit (3.4%) and kin run Tackle/Tackle/Brace — their only damage is Normal-element, which is super-effective against nothing, 0x vs Umbra and 0.5x vs Earth/Astral. All 56 Normal species have Normal-only damaging moves (round-robin mean win rate 32.8%, lowest of any type; Earth highest at 58.8%).
- **Templating is extreme:** only 47 distinct Lv<=50 learnsets exist across 504 species. Most-shared: 25x [Flame Charge / Fire Fang / Inferno Blast / Tectonic Slam]; 24x [Water Pulse / Aqua Tail / Tidal Surge / Hydro Cannon]; 24x [Cosmic Ray / Starfall / Supernova / Heavy Slam].

## 4. Balance fixes worth making in data

Every item below is fixable in `GanjukoSpecies.json` (custom file) or in the `GanjukoEngine.js` patch. Nothing here requires editing Classes.json or Skills.json (editor-owned).

1. **Rename the duplicate species in GanjukoSpecies.json.** Keep the first dex entries and rename the later duplicates: id **485** "Solaris" (duplicate of id 29) and id **487** "Terramonarch" (duplicate of id 30) get distinct names (e.g. "Solaris" → a new name for 485 only; same for 487). Two species sharing one name breaks dex/search display and any name-keyed logic.
2. **Catch floor scales with catchRate (engine patch, already SPEC §7).** 22 species sit at catchRate 3 and 25 at ≤ 10; under the current flat 0.12 floor a catchRate-3 legendary is a 12% full-HP basic-orb catch. Replace the floor with `max(0.015, catchRate-derived rate)` so catchRate 3 ≈ 1.5% at full HP and commons stay easy.
3. **Runtime move pool must cover the 24 two-damage final forms (engine patch, SPEC §5).** These fully-evolved species reach Lv50 with only 2 damaging moves because their template spends two slots on heal/status: ids 15, 42, 69, 96, 123, 150, 177, 204, 231, 258, 285, 312, 338, 356, 374, 392, 410, 428, 446, 464, 473, 482, 494, 501. The runtime type pool should grant each of them one additional damaging coverage move by Lv 30 so no final form fields fewer than 3 damaging moves.
4. **Fix the duplicated-Tackle learnsets via the same runtime pool (engine patch).** 20 species (ids 31, 58, 85, 112, 139, 166, 193, 220, 247, 274, 301, 328, 331, 349, 367, 385, 403, 421, 439, 457) learn skill ids [3, 1, 2, 3] — Tackle twice. The pool merge should dedupe repeated skill ids and backfill the freed slot with a coverage move.
5. **Give Normal an offensive identity (engine patch).** All 56 Normal species have Normal-only damaging moves; Normal is the only type with zero super-effective targets, is 0x vs Umbra and 0.5x vs Earth/Astral, and it shows: 24.4% matrix win rate (fails the SPEC 65% test bar), 32.8% round-robin mean (lowest type). Two engine-side levers, either sufficient to re-test: (a) the runtime move pool grants every Normal species one non-Normal coverage move by Lv 25; (b) in the engine damage hook, Normal-element moves get a 1.15x power bonus in Ganjuko battles as the documented compensation for having no 2x targets (the TYPE-CHART design assumed Normal moves carry the highest base power — the sim shows that is not enough). Re-run this simulator after the change; target Normal ≥ 42% overall.
6. **One chart constant for Water (engine patch chart table).** Water's 32.2% matrix win rate (also fails the SPEC bar) is chart-driven, not stat-driven — individual high-BST Water species top the round-robin while the type loses at equal stage. Change **Water → Nature from 0.5 to 1.0** in the engine's chart table (Water keeps its 0.5 vs Water, Nature keeps its 2x vs Water on defense). Re-sim before shipping any further chart changes; do not stack tweaks blind.
7. **Competitive stat scaling for the cannon tier (engine patch, Stadium/competitive only).** The top template — final form, AGI 373-405, BST 3046-3730, 4.0x+ cannon move — produced five species at ≥ 98.8% win rate (#57 Stormcresteon 100.0% over 83 battles, #165, #273, #93, #105). Wild/story play can keep them as legendaries; in Stadium mode the engine should normalize battler stats toward a fixed BST band (e.g. scale all six stats so BST = 3000) so speed-tier + cannon does not auto-win. Do **not** nerf the species data itself — #504 GenesisOmega (BST 3730, the dex capstone) sits at 92.1% and is fine as a story legendary.
8. **No action needed:** evolution chains are clean (0 broken targets, 0 bad evolveLv, 0 cycles), every species has a damaging STAB move by Lv50 (0 missing), and no learnset references a missing skill. Battler art needs no *data* fix either — 0 battlerNames are missing from img/enemies — but 471/504 species share a stock battler with another species and only 22 custom `Ganjuko_` battlers exist; that is the engine fallback/hue resolver's job (SPEC §1), not a JSON edit.
